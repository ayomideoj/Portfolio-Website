PROBLEM

The problem I solved

In Nigeria overprised housing can be a problem as well as using seed money in a property for scamming and property availability. The features designed and prototyped into this project solves each problem.

Key features

  • i. In-app communications system (for tenants and landlords)
  • ii. Different types of shortlets and extended leases to choose from(e.g apartments, hotels)
  • iii. Seed money is stored within the aplication and is only released when the tenant as moved in
